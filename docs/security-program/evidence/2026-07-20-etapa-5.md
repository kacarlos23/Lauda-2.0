## Riscos residuais prioritarios

1. Auditorias historicas anteriores a esta etapa contem payloads livres e podem conter PII; saneamento/retencao exigem decisao de Privacy/Security.
2. A ausencia de ledger permite reintroduzir dados eliminados em um restore.
3. Sem SIEM/canal/owners, eventos podem existir mas nao gerar resposta.
4. Gates de configuracao nao substituem IAM, KMS, backup e separacao efetivamente provisionados.
